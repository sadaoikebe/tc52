# TC52（有線）：向きのある部品の 1 番ピン・極性のシルク表示（2026-11-14）

対象：`main` の 080c222（CPL 回転監査の直後）。向きのある 9 種 12 点（全点 Bottom 実装）。
目的：JLCPCB の実装確認（目視）が、1 番ピン・カソードの位置を基板のシルクだけで迷わず照合できるようにする。
特に、EasyEDA にランドが無く照合できなかった X2（C27636964）と、回転補正を入れた U3・U4・U6・U7・U8（[`../tc52-rotation-audit/`](../tc52-rotation-audit/README.md)）を優先した。

**変更は B.SilkS（裏面シルク）だけ。** 基板ファイルに、グループ `pin1-markers` としてボード上の図形を 12 個追加した（追加のみで、既存行の変更・削除は 0 行）。
フットプリントは編集していない（編集するとライブラリとの差異（`lib_footprint_mismatch`）になるため）。銅・パッド・部品配置・回路図・F.SilkS は変わっていない。

## 部品ごとの現状判定と変更

座標は KiCad の基板座標（mm、表から見た座標）。比較画像 [`before-after.png`](before-after.png) は裏面から見た向き（左右反転）で、赤が 1 番パッド。

| --- | --- | --- | --- |

### 隙間（`check-markers.txt`）

各マーカーから、パッドのソルダーマスク開口・他のシルク・基板外形までの最短距離。

- パッド開口まで：**最小 0.199 mm**（X2 の L 字の縦線から X2 の 1 番・4 番。元の L 字と同じ距離）。そのほかはすべて 0.2 mm 以上。開口に重なるものは 0 件。
- 他部品のシルクまで：最小 0.070 mm（X2 の角の丸から R26 の線）。重なるものは 0 件。
- X2 の太い L 字と角の丸は、X2 自身の L 字の上に重ねている（意図どおり）。
- B.Cu の GND ベタの上にはシルクが載るが、ソルダーマスクの上なので製造上の問題はない（silk_over_copper はマスク開口との重なりだけが対象）。

## 検査（kicad-cli 10.0.8）

| 項目 | 従来値（080c222） | 変更後 |
| --- | --- | --- |
| DRC エラー／未接続／回路図との不一致 | 0 / 0 / 0 | 0 / 0 / 0 |
| DRC 警告 | 15（silk_overlap 8、silk_over_copper 4、silk_edge_clearance 3） | **21**（silk_overlap **14**、silk_over_copper 4、silk_edge_clearance 3） |
| ERC | エラー 0、警告 6（lib_symbol_mismatch） | 同じ |
| check_spec | 12/12 ok（note 2） | 12/12 ok（note 2）。出力は従来と同一（`check_spec-2026-11-14.txt`） |

**増えた警告 6 件はすべて silk_overlap で、相手はすべて X2 自身の L 字**（太線 2 本 × 元の L 字の 2 本の線、角の丸 × 2 本の線）。X2 の L 字を太線で上書きした意図どおりの重なりで、他部品との干渉ではない。
silk_over_copper（マスク開口との重なり）は増えていない。従来の 15 件は 1 件も変わっていない。

## 製造出力

`python3 pcb/jlcpcb/export.py` で再生成した。

- **CPL（`ts52k-cpl.csv`）は再生成前とバイト単位で同一**（SHA-256 `92451e74…`、manifest も同じ値）。080c222 の回転補正は保たれている：U3 90、U4 90、U6 90、U7 90、U8 90（補正前の KiCad 値は −90、0、−90、0、0）。X2 は 180（未補正のまま）。
- BOM も同一。ガーバー ZIP は `ts52k-B_Silkscreen.gbo` だけが変わり、他の 13 ファイルは日付行を除いて同一。
- `manifest.json`：`ts52k.kicad_pcb` とガーバー ZIP のハッシュ、`drc_warnings` 15→21 を更新。記録されたハッシュはすべて実ファイルと一致する。
- `ts52k.kicad_pro`・`.kicad_prl`・ロックファイルは DRC の前後で変わっていない。

## 再実行

リポジトリ直下から（pcbnew が必要なのでシステムの python3）：

```sh
/usr/bin/python3 -I docs/tc52-silk-pin1/check_markers.py pcb/ts52k.kicad_pcb docs/tc52-silk-pin1/markers.json
```

`markers.json` は追加した図形の一覧（丸は外径、線は線幅。丸は線幅 0.1 mm の塗りつぶし円として描いてあり、外径が表の値になる）。
